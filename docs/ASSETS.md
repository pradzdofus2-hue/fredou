# Ressources visuelles

Les 72 portraits vectoriels `public/art/card-1.svg` à `card-72.svg`, le décor `hero.svg` et le favicon sont créés par `scripts/generate-art.mjs` pour FREDOU. Aucun portrait, logo, texte ou asset Kyara n'a été importé. Les illustrations varient en décor, palette, visage, coiffure, accessoires et équipement dans trois univers fictifs. Elles constituent un jeu de démonstration stylisé et pourront être remplacées indépendamment du moteur.

Les icônes de l'interface proviennent de lucide-react (licence ISC). Les polices variables **DM Sans** (400–700) et **Manrope** (400–800), sous licence SIL Open Font License 1.1, sont embarquées en WOFF2 latin dans `public/fonts`. Aucun téléchargement de police extérieur n’est effectué au lancement. Sources officielles : [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans), [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope). Les licences originales sont conservées dans `public/fonts/DM-Sans-OFL.txt` et `public/fonts/Manrope-OFL.txt`. Fichiers récupérés le 24 octobre 2026 auprès de Google Fonts, sans modification. Les dépendances npm conservent leurs licences dans leurs distributions.

## Typographie de la nouvelle interface

La reconstruction visuelle utilise désormais trois familles libres, téléchargées directement auprès de Google Fonts le 24 octobre 2026, avec des fichiers WOFF2 latin embarqués : **Zen Kaku Gothic New** (400, 500, 700, 900) pour le texte, **Unbounded** (400, 600, 700, 900) pour les titres et **JetBrains Mono** (400, 700) pour les légendes et compteurs. Les familles proviennent des dépôts officiels [Zen Kaku Gothic New](https://github.com/google/fonts/tree/main/ofl/zenkakugothicnew), [Unbounded](https://github.com/google/fonts/tree/main/ofl/unbounded) et [JetBrains Mono](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono). Les licences SIL Open Font License originales sont présentes dans `public/fonts/zenkakugothicnew-OFL.txt`, `public/fonts/unbounded-OFL.txt` et `public/fonts/jetbrainsmono-OFL.txt`.

Les fichiers de polices ont été obtenus via le service officiel `fonts.googleapis.com` / `fonts.gstatic.com`, sans récupération d’asset depuis Kyara. Leur chargement est intégralement local. Le nouvel emblème FREDOU est un tracé SVG géométrique original dans le composant de navigation ; le symbole de fond et les effets du carrousel sont construits en CSS original. Les dispositions et proportions découlent des observations publiques consignées dans l’audit ; aucun CSS du site de référence n’est copié.
